# Support

If you need help with Ease State Helper, there are several ways to get support.

## Community Support

- **Discord**: Join our [Discord server](https://discord.gg/8NcC7cn3) to chat with other users and the maintainers. This is the fastest way to get help with small questions or to discuss ideas.
- **GitHub Discussions**: Use the [Discussions tab](https://github.com/y3l1n4ung/ease/discussions) on our GitHub repository for longer-form questions, RFCs, and showcase.
- **Stack Overflow**: You can also ask questions on Stack Overflow using the `flutter` and `ease_state_helper` tags.

## Reporting Bugs

If you've found a bug, please [open an issue](https://github.com/y3l1n4ung/ease/issues/new?template=bug_report.md) on GitHub. Be sure to include a minimal reproduction code sample.

## Feature Requests

Have an idea for a new feature? Please [open a feature request](https://github.com/y3l1n4ung/ease/issues/new?template=feature_request.md) to discuss it.
